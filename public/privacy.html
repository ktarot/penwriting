개인정보처리방침 · 한국어

PenWriting은 회원가입이나 로그인 없이 동작하며, 개인정보를 수집하거나 외부로 보내지 않습니다.

설정, 학습 기록, 내 문장, 쓰던 필기는 이 기기의 앱(브라우저) 저장소에만 저장됩니다. 개발자를 포함해 누구에게도 전송되지 않습니다.

음성 듣기는 기기에 설치된 음성 엔진을 사용합니다. 광고, 사용 통계 수집, 추적 기능이 없습니다.

저장된 기록은 [기록] 화면의 [전체 기록 삭제]로 지울 수 있으며, 앱을 삭제하거나 브라우저 데이터를 지우면 모두 사라집니다.

앱 화면과 학습 데이터 파일은 GitHub Pages에서 내려받습니다. 이때 일반적인 웹 접속처럼 GitHub가 접속 기록을 처리할 수 있습니다.

문제나 제안은 GitHub 저장소의 Issues에 남겨 주세요. GitHub Issues

시행일: 2026-11-18

Privacy policy · English

PenWriting works without sign-up or login. It does not collect personal information or send it anywhere.

Settings, your practice log, your texts and unfinished writing are stored only in the app's (browser's) storage on this device. They are not sent to anyone, including the developer.

Listening uses the speech engine installed on your device. There are no ads, no usage analytics and no tracking.

You can erase saved records with [Delete all records] on the Log screen. Uninstalling the app or clearing browser data removes everything.

The app and its lesson files are downloaded from GitHub Pages. As with any website visit, GitHub may process access logs.

Please report problems or suggestions in the Issues section of the GitHub repository. GitHub Issues

Effective: 2026-11-18

プライバシーポリシー · 日本語

PenWriting は会員登録やログインなしで動作し、個人情報を収集したり外部に送信したりしません。

設定・学習記録・マイ文章・書きかけの字は、この端末のアプリ(ブラウザ)の保存領域にのみ保存されます。開発者を含め、誰にも送信されません。

音声は端末にインストールされた音声エンジンを使います。広告、利用統計の収集、トラッキングはありません。

保存した記録は[記録]画面の[すべての記録を削除]で消せます。アプリを削除するか、ブラウザのデータを消すとすべて消えます。

アプリと学習データは GitHub Pages からダウンロードされます。一般的なウェブ閲覧と同様に、GitHub がアクセスログを処理する場合があります。

不具合やご意見は GitHub リポジトリの Issues にお寄せください。 GitHub Issues

施行日: 2026-11-18

Chính sách quyền riêng tư · Tiếng Việt

PenWriting hoạt động không cần đăng ký hay đăng nhập. Ứng dụng không thu thập và không gửi thông tin cá nhân ra ngoài.

Cài đặt, nhật ký luyện tập, câu của bạn và bài đang viết dở chỉ được lưu trong bộ nhớ của ứng dụng (trình duyệt) trên thiết bị này, không gửi cho bất kỳ ai, kể cả nhà phát triển.

Tính năng nghe dùng bộ đọc giọng nói có sẵn trên thiết bị. Không có quảng cáo, không thu thập thống kê, không theo dõi.

Bạn có thể xóa dữ liệu bằng [Xóa toàn bộ] ở màn hình Nhật ký. Gỡ ứng dụng hoặc xóa dữ liệu trình duyệt sẽ xóa tất cả.

Ứng dụng và tệp bài học được tải từ GitHub Pages. Như khi truy cập mọi trang web, GitHub có thể xử lý nhật ký truy cập.

Vui lòng gửi lỗi hoặc góp ý tại mục Issues của kho GitHub. GitHub Issues
